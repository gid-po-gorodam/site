# Гид по городам

Готовый одностраничный адаптивный сайт для рекламы каналов в MAX.

## Файлы
- index.html — структура страницы
- style.css — весь дизайн и адаптивность
- script.js — меню и интерактивные элементы

## Как подключить реальные каналы MAX
В `index.html` найдите:

    href="#"

и замените на настоящую ссылку конкретного канала, например:

    href="ССЫЛКА_НА_ВАШ_КАНАЛ"

## Как добавить больше каналов
Скопируйте один блок:

    <a class="channel">...</a>

внутри нужного города.

## Запуск
Для локальной проверки достаточно открыть `index.html` в браузере.

## Публикация
Это статический сайт — сервер не обязателен. Его можно разместить на любом обычном хостинге, который поддерживает статические HTML-файлы.
